Файли розміщено в [релізі v1](https://github.com/bigdata-16md-2026/bigdata-data/releases/tag/v1). Тека [pipeline/](pipeline) містить скрипти, якими зібрано знімок (для відтворюваності); для виконання робіт вона не потрібна.

## Джерела, ліцензії й умови використання

- **Знімок** (`zt_*`, крім `zt_contacts_synth.parquet`) зібрано через публічний API [ProZorro](https://prozorro.gov.ua). Це відкриті дані відповідно до ст. 10-1 Закону України «Про доступ до публічної інформації»: їх можна вільно використовувати за умови посилання на джерело (ProZorro, https://prozorro.gov.ua).
- **Архів** (`archive_*`) побудовано з набору [ProZorro Ukraine Procurement 2022–2025](https://www.kaggle.com/datasets/romankachmar/prozorro-ukraine-procurement-2022-2025) (Kaggle, автор Roman Kachmar), ліцензія CC0. CSV перетворено на Parquet і додано колонки `buyer_region` і `sector`; `archive_buyers` і `archive_competitive` обчислено з нього.
- **Синтетичні контакти** (`zt_contacts_synth.parquet`) згенеровано для курсу; таких людей не існує.
- **Скрипти** в теці `pipeline/` призначено для навчання; умови їх повторного використання визначає автор курсу.

## Персональні дані

Усі файли, крім синтетичного, побудовано з відкритих даних ProZorro, які будь-хто може отримати з порталу чи через API.

- **Знімок.** Під час збору не зберігаються дані контактних осіб замовників (ПІБ, телефони, адреси електронної пошти) і пропозиції учасників (лишається тільки їх кількість). Переможця збережено, лише якщо це юридична особа (код ЄДРПОУ і назва); ФОП замінено на «ФОП (приховано)». Адреси електронної пошти у вільному тексті описів замінюються на `[пошта]`. Так реалізовано принцип мінімізації даних (`bd.minimize` у [pipeline/bd](pipeline/bd/__init__.py)); перед публікацією це перевіряється автоматично. Описи складають самі замовники, тому інші згадки про людей у них (наприклад, прізвище відповідальної особи) автоматично не виявляються.
- **Архів** не мінімізовано. Учасника в ньому подано ідентифікатором `supplier_id`: здебільшого це 8-значний код ЄДРПОУ або 10-значний РНОКПП фізичної особи — підприємця, тобто персональні дані, а в частині рядків там записано й ПІБ ФОП. Окремої колонки з назвою учасника немає.
- Контакти в `zt_contacts_synth.parquet` синтетичні: таких людей не існує.
